How This Site Was Built

This website was created as a final project for our Web Technologies course. All HTML pages were written from scratch using modern web standards. We utilized a robust semantic structure, ensuring that the site is accessible and easy to read for both humans and search engines. I used Visual Studio Code as my primary code editor. When writing and saving files, I constantly used the keyboard shortcut Ctrl + S to ensure no data was ever lost.

The code relies on standard tags such as <header>, <main>, and <footer>. Here is a brief example of how a semantic tag looks in our raw source code:

<footer>
    <p>Contact us at Arubeauty</p>
</footer>

During the testing phase, the W3C validator returned the following success message for all our pages: Document checking completed. No errors or warnings to show. This confirms that our markup is clean and fully compliant with HTML5 specifications.

Typography and Assets

All text content was written originally, detailing the real services, contact information, and pricing provided by Arubeauty studio. The photographs used across the site are authentic images from the studio's portfolio, showcasing real makeup application and techniques. For more information about web standards and semantic elements, you can visit the MDN Web Docs.

I carefully selected the semantic tags to represent the structure of the document accurately. By avoiding generic containers where possible, the site becomes more accessible to screen readers.

Working on this project taught me a lot about the core building blocks of the internet. It was a challenging but highly rewarding experience.
