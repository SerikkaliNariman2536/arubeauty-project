# Arubeauty — Makeup Studio & Training Courses

This repository contains the project for Assignment 1 of the Web Technologies course[cite: 2].

## Project Overview
This is a 4-page static website built entirely with raw HTML5. Per the assignment requirements, no CSS, JavaScript, or frameworks were used. The site demonstrates proper semantic web structure, tables, and web forms based on a real, physically existing organization in Astana.

**Author:** Serikkali Nariman

## File Structure
* `index.html` — The main page containing the studio's history, location, and core philosophy.
* `services.html` — Contains a structured data table with service prices and training course descriptions.
* `booking.html` — A client registration page utilizing a comprehensive HTML5 form.
* `colophon.html` — A technical page explaining the site's creation process and the semantic tags utilized.
* `images/` — A directory containing the 3 original, non-stock photographs required for the project[cite: 2].

## How to Run
Since this project uses no external dependencies or server-side scripts, simply clone the repository and open `index.html` in any modern web browser.
